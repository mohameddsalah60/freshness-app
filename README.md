# فحص الصلاحية — Vercel

موقع عربي لتدقيق صلاحية المنتجات الطازجة. السجل مشترك: أي شخص يفتح الموقع يرى نفس الفحص الحالي ونفس السجل.

## النشر على Vercel (4 خطوات)

1. ارفع مجلد المشروع إلى GitHub (أو شغّل `vercel` من داخل المجلد).
2. في Vercel: **Add New → Project** واختر المستودع. لا تغيّر أي إعدادات (Framework: Other).
3. من تبويب **Storage** في المشروع: **Create → Upstash Redis** (من Marketplace) ثم **Connect Project**. هذا يضيف متغيرات البيئة تلقائيًا (`KV_REST_API_URL` و`KV_REST_API_TOKEN`).
4. اضغط **Redeploy** حتى يقرأ المشروع المتغيرات. افتح الرابط وسجّل أول منتج.

إذا ظهر أسفل الصفحة «وضع محلي» فهذا يعني أن قاعدة Redis لم تُربط بعد، والسجل وقتها يُحفظ على الجهاز فقط.

## البنية

| الملف | الوظيفة |
|---|---|
| `public/index.html` | الواجهة كاملة |
| `public/products.txt` | قاعدة المنتجات (38,882 منتجًا من ملف 2026-08-20) |
| `api/state.js` | قراءة الفحص الحالي والسجل |
| `api/batches.js` | إضافة وتعديل وحذف دفعة في الفحص الحالي |
| `api/finish.js` | إنهاء الفحص ونقله إلى السجل |
| `scripts/build-products.py` | يبني `products.txt` من ملف CSV |

## قواعد السحب من الرف

يُسحب المنتج من الرف قبل تاريخ الانتهاء المطبوع بعدد الأيام التالي، وتُحسب الحالات (أحمر، برتقالي، أصفر، أخضر) على تاريخ السحب:

| النوع | السحب قبل الانتهاء | ما يشمله |
|---|---|---|
| عيش | يوم | خبز عربي وبلدي وتوست ولفائف (القسم Bakery: Flatbread / Toast / Buns & Rolls) |
| لحوم ودواجن | يومان | دواجن وبقري وضأن غير المجمد |
| جبن فريش | يوم | جبن أبيض وفيتا وكريمي وقريش وأي منتج اسمه Fresh Cheese |
| خضار وفاكهة | يوم | خضار وفاكهة وأعشاب طازجة (بدون التمر والمجففات) |

لتغيير القواعد عدّل `pull_type` في `scripts/build-products.py` ثم أعد بناء الملف:

```
python3 scripts/build-products.py products.csv public/products.txt
```

لتغيير عدد الأيام عدّل الجدول `PULL` في أعلى سكربت `public/index.html`.
